# 🧾 Criando uma Planilha de Controle para Declaração de Imposto de Renda

## 📌 Descrição do Projeto

Este projeto consiste na criação de uma **planilha de controle de dados no Excel**, desenvolvida para facilitar a organização das informações necessárias para a **declaração de imposto de renda**.

A ferramenta permite centralizar dados fiscais de forma estruturada, utilizando:
- validações automáticas de dados  
- navegação facilitada entre abas  
- funções interativas e recursos visuais

## 🧩 Descrição do Desafio

O desafio propõe a construção de uma **ferramenta em Excel para organização de dados do imposto de renda**, funcionando como um **agregador de informações fiscais**.

A planilha permite ao usuário:
- Registrar e controlar informações essenciais para a declaração  
- Utilizar menus de navegação para acesso rápido às seções  
- Aplicar validações automáticas para garantir a consistência dos dados  
- Utilizar funcionalidades extras, como links rápidos e interações  

Toda a solução é desenvolvida exclusivamente no Excel, combinando **robustez funcional** com uma **interface amigável e intuitiva**.
