# 📊 Criando uma Ferramenta de Controle de Investimentos com Excel

## 📌 Descrição do Projeto

Este projeto consiste na criação de uma **ferramenta simples em Excel para simulação de investimentos em Fundos Imobiliários (FIIs)**.  
A planilha desenvolvida permite calcular:

- 💰 Valor total investido  
- 📈 Patrimônio acumulado  
- 🧾 Dividendos mensais  

O objetivo é auxiliar o usuário a compreender melhor o impacto de seus investimentos ao longo do tempo, oferecendo uma visão clara do potencial retorno financeiro.

O modelo pode ser utilizado como base para **futuras expansões e personalizações**, sendo uma solução prática e acessível para **investidores iniciantes**.

## 🧩 Descrição do Desafio

O objetivo deste desafio é aplicar os conceitos de Excel no desenvolvimento de uma **ferramenta prática de simulação de investimentos em Fundos Imobiliários**.

Com base na compreensão do funcionamento dos FIIs e nas principais dúvidas de investidores — como:
- Quanto investir  
- Por quanto tempo investir  
- Taxa de rendimento  
- Retorno mensal em dividendos  

o desafio consiste em construir uma planilha capaz de **automatizar cálculos financeiros**, tais como:
- Valor total investido  
- Patrimônio acumulado ao longo do tempo  
- Dividendos mensais estimados  

A solução visa proporcionar ao usuário uma **visão clara e objetiva do potencial retorno**, auxiliando na tomada de decisões mais informadas.
